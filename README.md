# เกมหลบผี (Ghost Game)

เกมเล่นบนเว็บ เขียนด้วย HTML, CSS และ JavaScript

**เล่นได้ที่:** https://ekkaphonz.github.io/ghost-game/

## วิธีเล่น

| ปุ่ม | ทำอะไร |
|------|--------|
| W A S D หรือปุ่มลูกศรบนจอ | เดิน |
| คลิกซ้าย | ตีลูกไฟกลับไปหาผี |
| คลิกขวาค้าง | บล็อกลูกไฟ |

- ผีจะเดินตามและยิงลูกไฟใส่ทุก 1.5 วินาที
- โดนลูกไฟ 5 ลูกแพ้
- ตีลูกไฟกลับไปโดนผี 3 ลูก ผีตาย แล้วเกิดใหม่ใน 3 วินาที

## ไฟล์

- `index.html` — หน้าเกม
- `styles.css` — หน้าตาเกม
- `app.js` — โค้ดเกม
